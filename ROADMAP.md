# ROADMAP

Глобальный план развития mdview. Отмечайте выполненные пункты `[x]`,
частично выполненные — пометкой _(в работе)_. Принятые архитектурные решения — в
разделе «Решения» в [AGENTS.md](AGENTS.md).

**Версия 1.0 = фазы 0–4 + фаза 5 (качество) + пункты фазы 6, помеченные «1.0».**
**Формат поставки — самодостаточная portable-сборка: распаковал → запустил → работает,
ничего не устанавливая.**

## Фаза 2. Mermaid

Встроенный рендер на нативном крейте `merman`, без Node.js —
см. [docs/research/mermaid.md](docs/research/mermaid.md).

- [x] Исследование: нативные крейты vs JS-движок → выбран `merman` 0.9
- [ ] Трейт `DiagramRenderer` + реализация на `merman` (`default-features = false`,
      `all-diagrams` + `complete-svg`, без `layout-elk`); версию зафиксировать
- [ ] SVG через `SvgPipeline::resvg_safe()` → растеризация `resvg` в текстуру egui
- [ ] Кэш по хэшу (исходник + тема + ширина)
- [ ] Фоновый поток с одним `Renderer`; debounce ~500 мс после паузы в наборе;
      Markdown при этом обновляется сразу
- [ ] Пока новая версия рендерится — показывать предыдущую картинку
- [ ] Заглушки: «rendering…», ошибка синтаксиса (текст ошибки от `merman`)
- [ ] Тема диаграмм следует текущей теме egui (`theme: dark / default` через site config)
- [ ] Масштабирование диаграммы под ширину панели, чёткость на HiDPI
- [ ] Проверить типы: flowchart, sequence, class, state, ER, gantt, pie, mindmap, timeline,
      gitGraph, journey (остальные — выборочно)
- [ ] Шрифт для подписей в `resvg`: системные (Segoe UI) или вшитый для детерминированности

## Не планируется

- Raw HTML внутри Markdown, YAML front matter — отображаются как есть
- Экспорт в PDF средствами приложения
- Старые кодировки (CP1251 и т.п.)
- Свой виджет редактора для файлов 1 МБ+
- CI на внешнем хостинге (проверки локальные)
- Установщик (поставка только portable)
- Зависимость релизной сборки от Node.js, `mmdc` или других внешних программ
