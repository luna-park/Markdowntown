# Markdowntown

A Markdown editor for Windows with a live preview and Mermaid diagrams.

- Editor with Markdown syntax highlighting, line numbers, find and replace
- Live preview: GitHub-flavored Markdown (tables, task lists, footnotes, alerts),
  syntax-highlighted code, local and remote images
- Math formulas: `$…$` inline and `$$…$$` on their own line (LaTeX, rendered like KaTeX)
- Mermaid diagrams rendered right in the preview — no browser or Node.js needed
- Tabs: each file in its own tab (right-click a tab to close the others); the open files
  come back the next time you start the app
- Synchronized scrolling between the editor and the preview
- Outline panel: jump to any heading in the editor and the preview
- Export to a single self-contained HTML file (styles, diagrams and local images inside);
  print it from the browser to get a PDF
- Light and dark themes, adjustable fonts, crash recovery for unsaved changes
- Portable: one `.exe`, nothing to install

## Getting started

1. Unzip the archive anywhere — a folder on your disk or a USB drive.
2. Run `markdowntown.exe`.
3. Open a file with **Ctrl+O**, drop a file onto the window, or pass it on the command line:
   `markdowntown.exe notes.md`.

To see everything the app can do, open `examples\showcase.md` (all Markdown elements,
formulas, a diagram) and `examples\mermaid.md` (all diagram types).

Windows SmartScreen may warn about an unrecognized app the first time you run it,
because the executable is not code-signed. Click **More info → Run anyway**.

**Requirements:** Windows 10 or 11, 64-bit. A graphics card is not required: the app
falls back to software rendering.

## Keyboard shortcuts

| Action | Keys |
|---|---|
| New / Open / Save / Save As | Ctrl+N / Ctrl+O / Ctrl+S or F2 / Ctrl+Shift+S |
| Close the tab / Next tab / Previous tab | Ctrl+W / Ctrl+Tab / Ctrl+Shift+Tab |
| Export to HTML | Ctrl+Shift+E |
| Show or hide the outline (list of headings) | Ctrl+Shift+O |
| Bold / Italic / Inline code / Link | Ctrl+B / Ctrl+I / Ctrl+E / Ctrl+K |
| Find / Replace | Ctrl+F / Ctrl+H |
| Go to line | Ctrl+G |
| Zoom the whole UI | Ctrl+Plus / Ctrl+Minus or Ctrl+mouse wheel; Ctrl+0 resets |
| Continue a list or quote | Enter at the end of an item (Enter on an empty item ends the list) |
| Indent / outdent a list item or the selected lines | Tab / Shift+Tab |
| Move the line (or selected lines) up / down | Alt+Up / Alt+Down |
| Duplicate / delete the line | Ctrl+Shift+D / Ctrl+Shift+K |
| Heading level 1–6 (again on the same level: plain text) | Ctrl+1 … Ctrl+6 |
| Check or uncheck a task (a plain list item becomes a task) | Ctrl+Enter |

Click a diagram in the preview to open it in a zoomable window. Links to other Markdown
files open them in a tab, and links like `#section` jump to the heading.

## Opening .md files with Markdowntown

**File → File association → Register for .md files** adds Markdowntown to the
"Open with" list for `.md` and `.markdown` files (for your user account only, no
administrator rights needed) and opens Windows Settings, where you choose Markdowntown as
the default app — Windows does not let programs do this themselves.

If you move `markdowntown.exe` to another folder, register again from the new copy.
**Unregister** removes everything; do it before deleting the app.

## Where settings are stored

Settings, the recent files list, recovery drafts and the log file are kept in a `data`
folder next to `markdowntown.exe`. If that folder is not writable (for example, in
`Program Files`), `%APPDATA%\Markdowntown` is used instead. Delete the folder to reset
everything.

If the app does not start, see `data\markdowntown.log`.

## Building from source

Requires Rust 1.95+ with the MSVC toolchain and the Windows SDK (installed with
Visual Studio Build Tools).

```powershell
cargo run -- examples/showcase.md   # debug build
.\check.ps1                         # formatting, lints, tests, build
.\package.ps1                       # release build and portable zip in dist\
```
