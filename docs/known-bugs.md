# Реестр дефектов

## Выделение строк в превью

Статус: влито в `master`. Исправление `e7c7af8` проверено в Windows debug.

До исправления фон служебного переноса перекрывал начало следующей строки. При быстром жесте выделение начиналось с позиции движения и пропускало первую строку. Ожидается выделение от места нажатия с читаемыми символами. [Регрессионный тест](https://github.com/luna-park/Markdowntown/blob/c5466a5e5dc7acc4eca54ed208672e83eb940ed0/src/preview.rs#L775).

## Ctrl+F в режиме "Только превью"

Статус: влито в `master`. Исправление `e7c7af8` проверено в Windows debug.

До исправления поиск открывался только при видимом редакторе. В режиме "Только превью" Ctrl+F должен открывать поиск по отображаемому тексту. [Тест поиска и переходов](https://github.com/luna-park/Markdowntown/blob/c5466a5e5dc7acc4eca54ed208672e83eb940ed0/src/tab.rs#L335).

## Прокрутка оглавления

Статус: влито в `master`. Исправление `e7c7af8` проверено в Windows debug.

До исправления текущий раздел мог подсвечиваться за пределами видимой части оглавления. При смене раздела список должен прокручиваться до активного заголовка. [Тест прокрутки оглавления](https://github.com/luna-park/Markdowntown/blob/c5466a5e5dc7acc4eca54ed208672e83eb940ed0/src/outline.rs#L148).

## Прокрутка при выделении в превью

Статус: влито в `master`. Исправление `ba84c89` проверено в Windows debug.

До исправления текст в превью не прокручивался за указателем и колесом во время выделения. При исчезновении виджета с одним из концов диапазона egui сбрасывал выделение. Теперь оба способа прокрутки сохраняют диапазон, в том числе если начало оказалось за пределами экрана. [Тесты прокрутки и копирования](https://github.com/luna-park/Markdowntown/blob/c5466a5e5dc7acc4eca54ed208672e83eb940ed0/src/preview.rs#L760-L770).

## Колесо при выделении в редакторе

Статус: влито в `master`. Исправление `c5466a5` проверено в Windows debug.

При захвате мыши полем редактора `ScrollArea` игнорировал колесо. Теперь колесо прокручивает редактор с зажатой левой кнопкой, а начало выделения сохраняется. [Тест прокрутки редактора](https://github.com/luna-park/Markdowntown/blob/c5466a5e5dc7acc4eca54ed208672e83eb940ed0/src/editor/mod.rs#L832).
