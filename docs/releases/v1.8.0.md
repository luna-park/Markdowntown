## What's new

- **Line commands in the editor.**
  - **Tab** / **Shift+Tab** nest a list item under the one above or move it back a level; with several lines selected, they indent or outdent all of them.
  - **Alt+Up** / **Alt+Down** move the line (or the selected lines).
  - **Ctrl+Shift+D** duplicates the line, **Ctrl+Shift+K** deletes it.
  - **Ctrl+1 … Ctrl+6** turn the line into a heading of that level; pressing the same keys again makes it plain text.
  - **Ctrl+Enter** checks or unchecks a task; on a plain list item it adds a checkbox.
- **Current line.** The line with the cursor has a faint background, and its number in the margin is highlighted.
- **More in the status bar.** The cursor position (line and column), the size of the selection in characters and words, and the word count of the document with an estimated reading time.
- **Go to line.** Press **Ctrl+G** (or **View → Go to Line…**), type a line number and press Enter. The editor and the preview both jump there.
- **Visible line breaks.** Two spaces at the end of a line start a new line inside a paragraph, but spaces are invisible. The editor now shows them on a tinted background, only where they actually make a line break. A backslash at the end of a line works too. See "Writing tips" in the README.

## Fixed

- A newly opened file sometimes showed up scrolled down in the preview, as if continuing from where another file had been. Files now always open at the top.

## Download

Unzip `Markdowntown-1.8.0-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
