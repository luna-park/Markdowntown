## Fixes

- **No more CPU load while idle.** Markdowntown kept redrawing its window about 100 times per second even when nothing changed, using 20–80% of a CPU core depending on the document size. Now it redraws only when needed, which saves battery on laptops.

## Download

Unzip `Markdowntown-1.4.3-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
