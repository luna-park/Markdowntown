## What's new

- **Tabs.** Every file opens in its own tab. Close a tab with Ctrl+W, the × button or a middle click; switch with Ctrl+Tab / Ctrl+Shift+Tab. Right-click a tab for Close, Close Others and Close Tabs to the Right. Opening a file that is already open switches to its tab.
- **Session restore.** The files you had open, and the active tab, come back the next time you start Markdowntown.
- **Links between documents.** A link to another Markdown file opens it in a tab; `other.md#section` and `#section` jump to the heading. Links to documents and images open them in their default app; other local files are only shown in Explorer, nothing is run.

## Fixes

- A wide table no longer stretches the rest of the preview past the panel edge: it scrolls sideways inside itself.

## Download

Unzip `Markdowntown-1.3.0-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
