## What's new

- **Tables fit the preview.** Long text in table cells wraps by words instead of making the table wider than the panel; short columns stay on one line. Columns have vertical separators, a line under the header and more room in each row. A table scrolls sideways only if even its longest words do not fit. Column alignment from Markdown (`:---:`, `---:`) is honoured for cells that fit on one line. HTML export wraps tables the same way.
- **Real bold text.** Headings, `**bold**` text and table headers in the preview use a bold font (Ubuntu Bold, the same family as the body text) instead of only a brighter colour.
- **Zoom with Ctrl+mouse wheel**, in addition to Ctrl+Plus / Ctrl+Minus: one notch is one zoom step. Over the diagram viewer, Ctrl+wheel still zooms the diagram.

## Fixes

- Links inside bold text or headings now have the link colour.

## Download

Unzip `Markdowntown-1.4.0-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
