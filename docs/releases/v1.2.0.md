## What's new

- **Outline panel** (View → Outline, Ctrl+Shift+O): the headings of the document; click one to jump to it in the editor and the preview.
- **Math formulas:** `$…$` inline and `$$…$$` on their own line, rendered like KaTeX — in the preview, highlighted in the editor and included in the HTML export.
- The archive includes `examples\showcase.md` (every supported element) and `examples\mermaid.md` (every diagram type).

## Download

Unzip `Markdowntown-1.2.0-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
