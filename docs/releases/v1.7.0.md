## What's new

- **Russian interface.** Markdowntown now speaks English and Russian. Choose the language in **View → Language** — it switches instantly, no restart needed. On first start the language follows Windows: Russian on a Russian Windows, English otherwise. Menus, dialogs, find and replace, tooltips and status messages are translated.
- **Alert titles in your language.** `> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` and `[!CAUTION]` are titled in the interface language (for example, "Примечание" and "Совет" in Russian) — in the preview and in HTML export.
- **Thicker horizontal rules.** A `---` line in the preview is now twice as thick, so it stands out from the rules under headings.

## Download

Unzip `Markdowntown-1.7.0-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
