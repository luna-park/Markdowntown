## Improvements

- **Smoother scrolling past code blocks.** Syntax highlighting is now cached, so visible code blocks are no longer re-highlighted on every frame. Common languages are prepared in the background at startup, and a language prepared once is shared by all tabs — the first code block of a language no longer causes a noticeable hitch.
- **Code blocks marked `rust`, `python` and similar** (language names rather than file extensions) are now highlighted with the same color theme as all other languages.
- **The right graphics card is used.** Markdowntown now renders on the graphics card your monitor is connected to (the primary monitor's card if monitors are connected to different cards). On desktops with the monitor plugged into a discrete card, frames are no longer drawn on the integrated graphics and copied over. Laptops keep using the integrated graphics that drives their screen.

## Download

Unzip `Markdowntown-1.5.1-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
