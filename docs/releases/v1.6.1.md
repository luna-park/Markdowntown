## Improvements

- **See where a link leads before clicking.** Hover a link in the preview, and the status bar shows its target: the web address, the heading it jumps to, the footnote, the Markdown file that opens in a new tab, or the file that opens with its default app (programs such as `.exe` are only shown in Explorer, never run). Links to files that don't exist are shown in red.
- **Footnote references are shown as `[1]`**, right next to the text, as on GitHub — easier to see and to click. HTML export uses the same style.

## Download

Unzip `Markdowntown-1.6.1-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
