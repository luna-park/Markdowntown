## What's new

- **Export to HTML** (File → Export HTML…, Ctrl+Shift+E): one self-contained file with styles, diagrams and local images inside. Its theme follows View → Theme; printing is always light, so you can print to PDF from the browser.
- **Open .md files with Markdowntown:** File → File association registers the app for `.md` and `.markdown` (for your account, no administrator rights) and opens Windows Settings to choose it as the default.

## Fixes

- Nested blockquotes get their own bar and indent in the preview.
- The root node of a mindmap is readable in the dark theme.

## Download

Unzip `Markdowntown-1.1.0-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
