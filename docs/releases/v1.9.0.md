## What's new

- **Right-click menu in the editor.** Cut, Copy, Paste and Delete; Bold, Italic, Code and Link; Duplicate Lines and Delete Lines; Select All. The shortcuts are shown next to the items. Right-clicking keeps the current selection.
- **Right-click menu in the preview.** Select some text and choose **Copy**.
- **Scrolling while selecting.** When you select text in the editor with the mouse and move the pointer above or below the window, the text scrolls — the farther the pointer, the faster.

## Download

Unzip `Markdowntown-1.9.0-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
