## Fixes

- **Tables inside list items** start on their own line under the item text and use the full item width. Previously they were squeezed into the end of the text line and cut off.
- **Lists look as on GitHub:** paragraphs of one list item no longer run together on a single line; code blocks and quotes inside an item start on a new line; items of a list separated by blank lines are spaced apart.
- **Task lists:** a space between the checkbox and its text.

## Download

Unzip `Markdowntown-1.4.2-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
