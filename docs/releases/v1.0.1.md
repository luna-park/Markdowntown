## Fixes

- Markdowntown no longer fails to start silently on some laptops with two graphics cards (for example AMD + NVIDIA with older drivers): it now prefers DirectX 12 and the integrated GPU. The selected graphics adapter is written to `data\markdowntown.log`.

## Download

Unzip `Markdowntown-1.0.1-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
