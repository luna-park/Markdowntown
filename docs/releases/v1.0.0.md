The first release of Markdowntown — a Markdown editor for Windows with a live preview and Mermaid diagrams.

- Editor with Markdown syntax highlighting, line numbers, find and replace, formatting shortcuts and list continuation
- Live preview: GitHub-flavored Markdown (tables, task lists, footnotes, alerts), syntax-highlighted code, local and remote images
- Mermaid diagrams rendered right in the preview — no browser or Node.js needed; click a diagram to zoom
- Synchronized scrolling between the editor and the preview
- Light and dark themes, adjustable fonts, recent files, crash recovery for unsaved changes
- Portable: one `.exe`, nothing to install

## Download

Unzip `Markdowntown-1.0.0-windows-x64.zip` anywhere and run `markdowntown.exe`. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
