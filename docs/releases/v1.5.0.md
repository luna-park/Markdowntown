## What's new

- **One window for all your files.** Opening a Markdown file from Explorer while Markdowntown is already running now opens it as a new tab in the running window (or switches to it if it is already open), instead of starting a second copy. The window is restored if it was minimized and comes to the front.
- **Readable width** (View → Readable width, on by default). In a wide window the preview is shown as a centered column of comfortable line length (about 85–90 characters), marked by faint dashed guides. Zooming with Ctrl+wheel scales the column together with the text.
- **Many tabs.** The tab bar's scroll bar no longer covers the tabs, the mouse wheel scrolls the tabs sideways, and the active tab is scrolled into view when you switch to it or open a file.

## Download

Unzip `Markdowntown-1.5.0-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
