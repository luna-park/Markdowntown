## What's new

- **F2 saves** the document, in addition to Ctrl+S.

## Fixes

- **File → File association** opens Windows Settings → Default apps again: on some systems it opened the Documents folder instead.
- Links to local documents and images in the preview open them with their default app more reliably.

## Download

Unzip `Markdowntown-1.4.1-windows-x64.zip` anywhere and run `markdowntown.exe` — nothing to install. Windows 10 or 11, 64-bit. SmartScreen may warn about an unrecognized app because the exe is not code-signed: **More info → Run anyway**.
